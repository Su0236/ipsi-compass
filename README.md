# 입시 나침반

중3부터 고교 선택, 과목 선택, 대입 준비까지 한곳에서 살펴보는 웹서비스 MVP입니다.

현재 포함된 학교, 대학·학과, 일정은 화면과 기능을 확인하기 위한 예시 데이터입니다. 실제 지원 전에는 반드시 학교와 대학의 공식 모집요강을 확인해야 합니다.

## 주요 기능

- 고교 검색과 최대 3개 학교 비교
- 대학·학과별 권장 이수과목 확인
- 과목 플래너
- 입시 일정과 캘린더 파일 내려받기
- 관심 목록과 알림 체험
- 공식 출처, 적용 학년도, 검토 상태 표시 구조
- Supabase 데이터베이스와 권한 정책 준비
- 관리자 검토 후 게시하는 자료 수집 구조

## 로컬 실행

Node.js 20.9 이상과 pnpm을 준비한 뒤 다음 명령을 실행합니다.

```bash
pnpm install
pnpm dev
```

브라우저에서 `http://127.0.0.1:3000`을 엽니다.

## 검사

```bash
pnpm typecheck
pnpm test
pnpm build
```

## Supabase 연결

1. `.env.example`을 참고해 `.env.local`을 만듭니다.
2. Supabase SQL Editor에서 `supabase/migrations/001_initial.sql`을 실행합니다.
3. 프로젝트 URL과 공개용 Publishable Key를 `.env.local`에 입력합니다.
4. 실제 자료 연결이 끝난 뒤 `NEXT_PUBLIC_DATA_MODE=live`로 변경합니다.

`SUPABASE_SERVICE_ROLE_KEY`는 서버 전용 비밀키입니다. GitHub에 올리거나 브라우저 코드에서 사용하면 안 됩니다.

## 자료와 광고 원칙

- 공식 API 또는 이용 허용이 확인된 자료만 수집합니다.
- robots.txt, 이용약관, 저작권, 상업적 이용 조건을 출처별로 확인합니다.
- 사용자 제공 전문가 의견은 공식 제도와 구분하며 원문을 재배포하지 않습니다.
- 제휴 링크는 승인된 링크와 고지 문구가 모두 설정된 경우에만 표시합니다.
- 광고는 교육정보, 검색 결과, 학교 비교 순위에 영향을 주지 않습니다.

## 아직 필요한 운영 정보

- Supabase 프로젝트와 공개용 키
- 학교알리미 API 키 및 항목별 상업 이용 조건 확인
- 우선 연결할 실제 학교·대학·학과 목록
- 운영자명과 문의 이메일
- 미성년자 가입·동의 정책의 법률 검토
- 쿠팡 파트너스 승인 링크, 배너 사용 권한, 최신 고지 문구
